# Newsroom AI Copilot

A multi-agent AI platform that helps journalists and editorial teams:

- Research topics
- Verify claims
- Generate headlines
- Review content quality
- Create social media posts
- Evaluate AI outputs

## Tech Stack

- Python
- LangGraph
- Gemini API
- Pydantic
- FastAPI
- Streamlit
- Docker

## Status

🚧 Currently in Architecture & System Design Phase
