# System Architecture

## Core Components

1. Streamlit UI
2. FastAPI Backend
3. LangGraph Orchestrator
4. Context Builder
5. Agent Layer
6. Evaluation Layer
7. Structured Results Layer

## High-Level Flow

User Input
→ Context Builder
→ Research Agent
→ Fact Check Agent
→ Headline Agent
→ Editorial Review Agent
→ Social Media Agent
→ Evaluation Layer
→ Results Dashboard

## Design Principles

- Separation of concerns
- Multi-agent architecture
- Structured outputs
- Shared graph state
- Human-in-the-loop review
- Source transparency
