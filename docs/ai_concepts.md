## AI Agent
An AI agent is a software component that performs
a specific task using an LLM, tools, and context.
Example - Research Agent

## Multi-Agent Systems
Multiple specialized agents collaborating together.

Why Used
1. Easier maintenance
2. Better scalability

## Context Engineering
Providing the right information to an LLM.

Example - Research findings become context for Fact Check Agent.
